# NATS Micro Extensions

NATS Micro Extensions is a set of utilities providing additional features to the NATS `micro` package of nats.go client.

## Installation

```bash
go get github.com/synadia-io/orbit.go/microext
```

## Utilities

### OpenAPI

The OpenAPI micro extension provides a well-defined interface for describing
your NATS `micro` service using the OpenAPI specification.
